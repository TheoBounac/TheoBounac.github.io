# Portfolio — Théo Bounaceur

Portfolio statique réalisé en HTML et CSS, prêt à être publié avec GitHub Pages.

## Personnalisation

- Remplacer l'image grise en haut de page par une image de couverture.
- Ajouter le CV dans `assets/cv-theo-bounaceur.pdf`.
- Remplacer l'adresse LinkedIn dans `index.html` par le lien du profil.
- Remplacer les photos et les textes des projets, puis compléter les listes « Mon parcours » et « Extra ».

## Prévisualiser en local

Ouvrir `index.html` dans un navigateur. Avec VS Code, l'extension Live Server permet de voir les changements après chaque sauvegarde.

## Publier avec GitHub Pages

Dans les paramètres du dépôt GitHub, choisir **Pages**, puis **Deploy from a branch**, la branche `main` et le dossier `/(root)`.
