# Portfolio — Théo Bounaceur

Site statique HTML/CSS/JavaScript prêt pour GitHub Pages.

## Personnalisation indispensable avant publication
1. Remplacer les liens GitHub, LinkedIn et email dans `index.html`.
2. Ajouter le CV PDF dans `assets/` sous le nom `cv-theo-bounaceur.pdf` (ou modifier le lien).
3. Remplacer le bloc `TB` par une vraie photo de profil.
4. Compléter le parcours académique avec les intitulés, établissements et dates exacts.
5. Vérifier les descriptions des projets et remplacer chaque lien `https://github.com/` par le dépôt correspondant.
6. Les photos des projets sont des illustrations provisoires générées pour la maquette : remplace-les par tes propres captures/vidéos.
7. Modifier les textes et compétences pour ne garder que les informations exactes.

## Tester en local
Ouvrir `index.html` dans un navigateur.

## Publier avec GitHub Pages
Créer un dépôt public nommé exactement `TON-PSEUDO.github.io`, puis envoyer tout le contenu de ce dossier à la racine de la branche `main`.
Dans le dépôt : Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main` → Folder: `/(root)` → Save.
Le site sera publié à `https://TON-PSEUDO.github.io`.
